# AnimeChat — готовый MVP-мессенджер

AnimeChat — веб-мессенджер с тёмной неоновой аниме-темой.

## Функции
- регистрация и вход;
- JWT-сессия;
- профиль и аватар (data URL для MVP);
- поиск пользователей;
- друзья;
- личные комнаты;
- групповые чаты;
- создание группы;
- сообщения в реальном времени;
- история сообщений в SQLite;
- индикатор «в сети»;
- набор emoji/стикеров;
- голосовые и видеозвонки WebRTC;
- групповые звонки через mesh-WebRTC;
- STUN и опциональный TURN;
- адаптивный интерфейс для телефона и ПК.

## Запуск локально

Node.js 20+:

```bash
cp .env.example .env
npm install
npm start
```

Открой:
`http://localhost:3000`

Для теста звонка открой приложение в двух браузерах/устройствах, создай аккаунты и открой одну и ту же комнату.

## GitHub

Загрузи содержимое архива в репозиторий. `.env` и база данных исключены из Git.

## Публикация

Для реального публичного сервиса нужны:
- домен;
- HTTPS;
- Node.js-хостинг/VPS;
- TURN-сервер для стабильных звонков через NAT/мобильные сети;
- резервное копирование базы;
- rate limiting и защита от спама;
- PostgreSQL/object storage при росте проекта.

Домен сам по себе сервером не является: DNS должен указывать на хостинг/VPS.

## TURN

В `.env`:
```env
TURN_URL=turn:example.com:3478
TURN_USERNAME=...
TURN_CREDENTIAL=...
```

Для production лучше использовать временные TURN credentials, а не постоянный пароль в клиенте.

## Важно

Это готовый к запуску MVP, но не утверждается как полностью production-hardened коммерческий сервис. Для публичного запуска нужно выполнить инфраструктурные и security-настройки выше.
