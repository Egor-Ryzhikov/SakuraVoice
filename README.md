# 🌸 Sakura Messenger

Аниме-мессенджер в стиле современных мессенджеров, подготовленный для публикации на GitHub Pages.

## Что уже работает
- список чатов;
- поиск;
- фильтры «Все / Непрочитанные / Группы»;
- открытие чатов;
- отправка сообщений;
- сохранение сообщений в `localStorage`;
- прикрепление имени файла;
- профиль;
- адаптация под телефон;
- аниме-фон;
- демо-ответ собеседника.

## Запуск
Просто открой `index.html` в браузере.

## GitHub Pages
1. Создай новый репозиторий на GitHub.
2. Загрузи все файлы из этой папки.
3. В репозитории открой **Settings → Pages**.
4. В разделе Source выбери **Deploy from a branch**.
5. Выбери `main` и папку `/root`.
6. Сохрани — GitHub выдаст адрес сайта.

> Сейчас это полностью рабочий браузерный прототип. Для настоящего Telegram-подобного сервиса с аккаунтами, общей базой данных, сообщениями между разными устройствами и настоящими звонками понадобится backend (например, Node.js + WebSocket + база данных).
