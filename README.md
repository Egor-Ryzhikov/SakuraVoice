# 🌸 Sakura Messenger — Final

Готовый full-stack аниме-мессенджер для GitHub + Render.

Возможности:
- регистрация и вход;
- PostgreSQL;
- личные онлайн-чаты;
- Socket.IO;
- Developer ✓;
- админ-панель;
- роли user/admin/developer;
- верификация;
- голосовые сообщения через микрофон;
- адаптивный интерфейс;
- готовый `render.yaml`.

## Быстрый запуск

```bash
npm install
npm start
```

Переменные `.env`:

```env
DATABASE_URL=...
JWT_SECRET=...
DEVELOPER_USERNAME=твой_логин
CLIENT_ORIGIN=*
```

## GitHub

Создай пустой repository и загрузи содержимое этой папки. Не загружай `.env` или пароли.

## Render

Создай PostgreSQL и Web Service из GitHub repository. Build: `npm install`, Start: `npm start`. Добавь переменные из `.env`.

`DEVELOPER_USERNAME` автоматически назначает указанному аккаунту роль developer и галочку ✓.

## Голосовые

В чате нажми 🎙️, разреши микрофон и нажми ⏹️. Запись отправляется как сообщение и воспроизводится через встроенный аудиоплеер.

Для крупного production-проекта аудио лучше хранить в объектном хранилище, а не в PostgreSQL.


## 📞 Аудио- и видеозвонки

Добавлены звонки между двумя пользователями через WebRTC и Socket.IO signaling.

- 📞 аудиозвонок;
- 📹 видеозвонок;
- входящий вызов;
- принять/отклонить;
- выключить микрофон;
- выключить камеру;
- завершить звонок.

WebRTC используется для передачи медиа между браузерами, а Socket.IO — для обмена сигнализацией (offer/answer/ICE). Браузер запрашивает разрешение на микрофон/камеру через `getUserMedia()`. Для production-проектов стоит добавить TURN-сервер: STUN помогает найти маршрут, но не гарантирует соединение во всех сетях.

Сайт должен работать по HTTPS, чтобы браузер разрешил доступ к камере и микрофону.
